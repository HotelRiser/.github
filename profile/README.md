## Who we are

**HOTELRİSER TEKNOLOJİ A.Ş.** is a hotel software company based at **Samsun Teknopark**, Türkiye.
We build one connected platform so independent and boutique hotels can sell directly, run daily operations and stay compliant without juggling separate tools.

## What we build

| | |
|---|---|
| 🌐 **Hotel website + booking engine** | Free and unlimited. A modern, SEO-ready direct booking site for every hotel. |
| 🔗 **Channel manager** | Rates and availability distributed to 150+ channels from one screen. |
| 🏨 **PMS** | Front office, reservations, folios, cashier, housekeeping, night audit, F&B POS, SPA and reports. |
| 📱 **Staff mobile app** | iOS and Android, included in the PMS plan. |
| 🛡️ **Compliance built in** | KBS guest notification automation, 5651-compliant guest Wi-Fi, e-Invoice integration. |
